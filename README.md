# SIM-INKINDO DKI

**SIM-INKINDO DKI (Sistem Informasi & Manajemen INKINDO DKI)** merupakan aplikasi web terpadu **DPP INKINDO DKI Jakarta** yang digunakan untuk mendukung pengelolaan data keanggotaan, layanan mitra kerja, dan pengelolaan konten informasi organisasi.

## Ringkasan Fungsi

- Pengelolaan data badan usaha anggota serta informasi sertifikasi terkait.
- Pengelolaan data dan layanan kemitraan kerja.
- Pengelolaan konten berita, informasi publik, dan materi beranda portal web.

## Teknologi

- PHP (CodeIgniter 4)
- Bootstrap & DataTables

## Hak Cipta & Penggunaan

Dikembangkan khusus untuk lingkungan **DPP INKINDO DKI Jakarta**. Penggunaan dan distribusi sistem mengikuti kebijakan internal organisasi.
